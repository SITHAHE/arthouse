# Контракт токенов (v2)

Имена (роли) заморожены во всех проектах. Меняются только **значения** — под стиль из `_factory/styles`. Всё живёт в `src/index.css` внутри `@theme`.

## Что изменилось в v2
**Форма и характер переехали из замороженного слоя в стилевой.** Радиусы, форма кнопок, интенсивность теней, рецепт обработки фото и темп моушна теперь ЗНАЧЕНИЯ, которые задаёт карточка стиля (поля `shape:`, `photo:`, `motion:`). Замороженными остались: имена ролей, ритм-шкала, a11y, reduced-motion, семантика статусов.

**Карантин орнаментов:** `.text-gradient`, `.glass`, `.grid-dots`, `.animate-floaty` — красные маркеры ИИ-дизайна (`checklists/design-ru.md`). Использовать только если поле `ornament:` карточки стиля явно разрешает конкретный класс.

## Как это работает
Tailwind v4 из каждого `--color-X` делает утилиты: `bg-X`, `text-X`, `border-X`.

## Роли — что заполнять под стиль

| Токен | Роль | Правило |
|---|---|---|
| `--color-bg` | фон страницы | не чистый `#000` (см. design-ru §3) |
| `--color-surface`, `-2` | карточки, уровни поверхности | чуть контрастнее bg |
| `--color-fg` | основной текст | контраст к bg ≥ 7:1 |
| `--color-muted` | вторичный текст | контраст к bg **≥ 4.5:1** |
| `--color-line` | границы, хайрлайны | видима в обеих темах |
| `--color-accent` | CTA, ссылки | ОДИН акцент, сатурация ≤ 80% |
| `--color-accent-hi` | ховер акцента | светлее/ярче |
| `--color-accent-contrast` | текст на заливке акцентом | ≥ 4.5:1 к accent |
| `--color-success/warning/danger` | статусы | **не трогать** |
| `--font-sans` | текст | пара из стиля, **кириллица обязательна** (`fonts/cyrillic-pairs.md`) |
| `--font-display` | заголовки | display-шрифт стиля |
| `--radius-sm/base/lg` | скругления | из `shape:` стиля (noir 0-6, fresh 12, космос 16-20) |
| `--radius-btn` | форма кнопки | из `shape:`; 999px только для капсульных стилей |
| `--shadow-soft/card` | тени | интенсивность стилевая; минимал глушит в 0 |
| `--img-filter` | обработка фото | один рецепт на сайт из `photo:` стиля |
| `--dur-1/2/3`, `--ease-*` | тайминги | базовые заморожены; медленные стили могут ×1.5 dur-3 |

## Не под стиль (заморожено)
Имена ролей, ритм-шкала (`.section-y*`, `.container-x`), семантика статусов, focus-ring, reduced-motion, контрастные пороги.
